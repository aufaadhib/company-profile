# Company Profile

Portfolio company profile berbasis Next.js 16 App Router, TypeScript strict, dan Tailwind CSS v4.

## Development

```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000).

## Verification

```bash
npm run lint
npx tsc --noEmit
npm run build
```
